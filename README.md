# ملاحظاتي 📝

دفتر ملاحظات شخصي وآمن، واجهة عربية RTL كاملة، مدعوم بـ **Supabase** كقاعدة بيانات سحابية (مصادقة + جداول + حماية RLS).

## التشغيل خطوة بخطوة

1. **افتح لوحة تحكم Supabase** ← *SQL Editor* ← *New query*، الصق محتوى `supabase-schema.sql` كاملاً واضغط **Run**.
2. افتح *Project Settings ← API*، انسخ **Project URL** و**anon public key** والصقهما في `supabase-config.js`.
3. افتح `index.html` في المتصفح (أو شغّل خادمًا محليًا مثل `python -m http.server 8765`).
4. أنشئ حسابًا بالبريد وكلمة المرور، ثم ابدأ التدوين — ملاحظاتك تُحفظ في سحابة Supabase تحت حسابك وحدك.

> عند تفعيل «Confirm email» في Supabase، أضف رابط موقعك في
> *Authentication ← URL Configuration ← Redirect URLs* ليعمل رابط تأكيد البريد.

## المزايا

- **مصادقة سحابية**: تسجيل ودخول بكلمة مرور يديرها Supabase Auth (تأكيد بريد، تجديد تلقائي للجلسة، جلسات متعددة التبويبات).
- **خصوصية تامة**: جدول `notes` محمي بـ RLS — `auth.uid() = user_id` — فلا يرى المستخدم إلا صفوفه، ولا يمكن لعميل أي مستخدم الوصول لغيره حتى لو عرّف استعلامًا يدويًا.
- **إدارة الملاحظات**: جلب، إضافة، تعديل، حذف ناعم (سلة) + استعادة + حذف نهائي، تثبيت، مفضلة، 7 ألوان.
- **حفظ تلقائي** أثناء الكتابة مع مؤشر «تم الحفظ ✓».
- **بحث فوري** وترشيحات (الكل / المثبتة / المفضلة / المحذوفة).
- **تصدير** الملاحظات إلى JSON.
- **وضع ليلي** وواجهة RTL بالكامل مع خط IBM Plex Sans Arabic وتجاوب مع الجوال.
- **اختصارات**: `Ctrl+N` ملاحظة جديدة، `Ctrl+K` بحث، `Ctrl+Enter` حفظ، `Esc` إغلاق.

## بنية المشروع

```
index.html            — الواجهة (شاشة الدخول + التطبيق + النوافذ) مع CDN الخاص بـ Supabase
styles.css            — نظام التصميم (فاتح/داكن، RTL، متجاوب)
app.js                — منطق Supabase (Auth + CRUD للملاحظات)
supabase-config.js    — رابط المشروع والمفتاح العام (anon) فقط
supabase-schema.sql   — SQL الجداول والفهارس والمشغّلات وسياسات RLS
README.md             — هذا الملف
```

## الأمان

- **الملف المحمي أنت**: `supabase-schema.sql` يُنفَّذ مرة واحدة من لوحة التحكم ولا يحتاج رفعه للموقع.
- **`supabase-config.js` يحوي المفتاح العام (anon) فقط** — وهذا مقصود أن يكون منشورًا مع أي موقع ثابت، وحمايته من RLS لا من إخفائه.
- **ممنوع منعًا باتًا** وضع مفتاح `service_role` أو أي مفتاح سري (secret) في هذا الملف أو أي ملف يُرفع للمستودع — فهو يتجاوز الحماية بالكامل.
- ملفات `.env*` و`*secret*` و`*service_role*` مُستبعدة عبر `.gitignore`.

## ملاحظات

- الموقع يعمل بلا إنترنت؟ لا — كل البيانات سحابية الآن (الوضع المحلي القديم استُبدل بالكامل).
- للاختبار المحلي استخدم: `python -m http.server 8765` ثم `http://127.0.0.1:8765`.
